# Video mẫu

Thư mục để chủ kênh gửi **video mẫu** cho Claude: kiểu dựng, nhịp cắt, chữ, hiệu ứng muốn làm theo.

**Cách gửi:** mở thư mục này trên GitHub → **Add file → Upload files** → kéo video (MP4) vào → bấm **Commit changes**.

- GitHub trên trình duyệt chỉ nhận file tối đa **25 MB**. Video nặng hơn: tải lên Google Drive (chia sẻ "Bất kỳ ai có đường liên kết"), rồi dán link vào file `links.md` trong thư mục này (Add file → Create new file).
- Đặt tên file ngắn, không dấu nếu được, ví dụ `tin-mau.mp4`.
- Muốn ghi chú điều thích ở video mẫu (giọng, chữ, nhạc, chuyển cảnh...), tạo kèm một file cùng tên, đuôi `.txt`, ví dụ `tin-mau.txt`.
